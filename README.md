# 🎓 Student Exam Performance Predictor

End-to-end ML project: predicts a student's maths score from background and reading/writing scores.

**🔗 Live demo:** https://student-performance-analysis-qwp9.onrender.com/

## Features
- ML prediction with grade, percentile, likely range and what-if improvement tips
- Interactive data-insights dashboard (Chart.js)
- REST API: `POST /api/predict`
- Input validation, health check, modular pipeline (ingestion → transformation → training → prediction)

## Tech stack
Python, Flask, scikit-learn, XGBoost, CatBoost, Pandas, Chart.js, Gunicorn, Render
